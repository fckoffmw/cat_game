# ПР-6. Этап Cloudflare Spectrum

Статус — ожидаются данные аккаунта, домена и публичного origin. Приложение Spectrum и правила firewall в этой работе пока не настроены.

Схема соединения — клиент → UDP Spectrum → игровой сервер с EncryptedTransport. В локальном прототипе используется UDP 7777. Для варианта методички можно выбрать внешний 9000 и направить его на origin:7777, указав клиенту внешний порт.

## Порядок настройки

1. Проверить доступность UDP Spectrum на аккаунте и подключить домен.
2. Запустить хост с зашифрованным транспортом на origin. Проверить прямое подключение с отдельного клиента до включения ограничений firewall.
3. Создать Spectrum-приложение для выбранного UDP-порта, указать адрес и порт origin. Proxy Protocol отключить, поскольку используемый UTP-драйвер ожидает собственный протокол с начала датаграммы.
4. Настроить ограничение доступа к игровому порту origin по актуальной схеме адресов Spectrum. Сохранить рабочий административный доступ к серверу.
5. На клиенте указать Spectrum-адрес и внешний порт в верхней левой панели подключения. Центральная кнопка меню пока использует localhost:7777.
6. Убедиться, что клиент проходит защищённое подключение и завершает матч через Spectrum. Проверить, что прямое подключение к игровому порту origin закрыто.
7. Сохранить скриншоты приложения, DNS и правил, журнал успешного подключения, выбранные DDoS-параметры и объяснение выбора.

Состав отчёта после настройки — домен, адрес/порт origin, внешний порт, фактический тариф, схема, разрешённые входящие порты, скриншоты панели, результат проверки через прокси и результат проверки закрытого origin. Эти значения заполняются по реальной конфигурации.

Актуальные ограничения сервиса, включая UDP-фрагментацию и параметры Proxy Protocol, проверяются по официальной документации. [Cloudflare Spectrum limitations](https://developers.cloudflare.com/spectrum/reference/limitations/)
