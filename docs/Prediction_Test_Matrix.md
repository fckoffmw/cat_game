# ПР‑4. Матрица тестов

**Версия:** Unity 6000.3.10f1, Netcode for GameObjects 2.7.0, development build для macOS. Хост и клиент — отдельные процессы на одном компьютере.

**Как эмулировалась сеть.** Встроенная эмуляция Unreal Engine (`NetEmulation.PktLag`) в Unity недоступна, поэтому использован UDP-посредник [`Tools/udp_lab.py`](../Tools/udp_lab.py): клиент подключается к порту посредника (7778), посредник пересылает пакеты хосту (7777) с заданной задержкой и потерями **в обе стороны**.

| Профиль | Команда | Задержка | Потери |
|---|---|---|---|
| Без эмуляции | автотест: посредник с `--delay 0 --loss 0`; вручную можно подключаться напрямую к порту 7777 | 0 | 0 |
| P1 | `python3 Tools/udp_lab.py --port 7778 --server 7777 --delay 100 --loss 0` | 100 мс в одну сторону | 0% |
| P2 | `python3 Tools/udp_lab.py --port 7778 --server 7777 --delay 175 --loss 4` | 175 мс в одну сторону | 4% |

**Автоматический запуск всех сценариев:** `python3 Tools/check_practice.py prediction Builds/Rooftop.app/Contents/MacOS/game_cats Builds/check-prediction` (профили `direct`, `baseline`, `prediction`, `loss`). Каждый сценарий делает три прыжка: допустимый, ранний (намеренное расхождение, клавиша F8) и допустимый после кулдауна.

## Как читать журнал

| Запись | Смысл |
|---|---|
| `INPUT #N` | Клиент сформировал команду №N с прыжком |
| `LOCAL_JUMP #N` | Клиент применил прыжок локально (предсказание) |
| `ACCEPT #N` / `REJECT #N` | Сервер принял или отклонил прыжок |
| `ACK #N after_ms=… delta_y=… replay=… server_y=…` | Клиент получил подтверждение: время с нажатия, сдвиг по высоте при коррекции, число неподтверждённых команд, высота на сервере |
| `VENT_OK` | Кот перепрыгнул центральный воздуховод |

## Ограничения

- Потери в T4 и T5 включались после подключения клиента. Попытка с потерями с первого пакета не прошла: клиент не вошёл за 50 секунд.
- Измерения сделаны на одном компьютере через посредник, а не по реальной сети.
- Плавность перемещения в T1 оценивалась вручную, количественного показателя нет.
- Перед защитой стоит повторить T1–T5 вживую и вписать наблюдения в таблицу.
