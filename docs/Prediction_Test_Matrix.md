# ПР‑4. Матрица сетевых проверок

Сборка 4253de2, хост и отдельный клиент macOS, UDP на loopback. В каждом прогоне один и тот же сценарий: пройти к центру, прыгнуть, приземлиться, запросить ранний прыжок, упереться в вентиляцию и перепрыгнуть её после завершения кулдауна. INPUT — фиксированный шаг считывания запроса, LOCAL_JUMP — первый локальный подъём, ACK — первый полученный снимок, подтверждающий эту или следующую команду. Время отсчитывается от INPUT; задержку клавиатуры и монитора стенд не измеряет.

| Тест | Условия и ожидание | Фактический результат |
|---|---|---|
| T1 | Без добавленной задержки. Клиент и хост видят игроков, движение и прыжок работают. | Клиент получил двух котов и 12 рыбок. Сервер принял допустимый прыжок №148. После упора при x=1,00 кот преодолел воздуховод и приземлился при x=−4,90. |
| T2 | 100 мс в одну сторону, 0% потерь, предсказание выключено. Клиент ждёт сервер. | Для №150 подъём стал виден при получении ответа через 283 мс, y поднялась с 1,080 до 1,194. |
| T3 | Те же 100 мс, предсказание включено. Подъём начинается в локальном шаге. | Для №149 локальная высота сразу изменилась с 1,080 до 1,194. Снимок пришёл через 249 мс; повторены 12 команд. |
| T4 | 175 мс в одну сторону, вероятность потери 4% в каждом направлении. Движение и разрешённое действие продолжаются. | Клиент локально прыгнул, хост подтвердил №150. Подтверждение дошло через 812 мс. Следующий разрешённый прыжок пересёк вентиляцию от x=1,00 до x=−5,00 без разрыва. |
| T5 | Те же потери. Клиент ошибочно разрешает прыжок в течение кулдауна. | Для №218 зарегистрированы LOCAL_JUMP и серверный REJECT. Через 813 мс авторитетная высота равна 1,080. К этому моменту локальная дуга уже закончилась. Чётко видимая вертикальная коррекция в контрольном прогоне при 100 мс составила −0,978. |

В T4/T5 ухудшение сети включено после синхронизации сцены, до начала маршрута. В отдельной попытке с потерями с первого пакета клиент не вошёл за 50 секунд. Устойчивость входа при таких потерях остаётся ограничением. При ручной демонстрации можно запустить посредник с нужным профилем сразу; для точного повторения измерений использовать автоматический сценарий.
