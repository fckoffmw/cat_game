# Коты на крыше

Учебный 3D-прототип для ПР‑4 и ПР‑5. Редактор Unity **6000.3.10f1**, Netcode for GameObjects **2.7.0**, Unity Transport. Версии зависимостей закреплены в Packages/packages-lock.json.

## Как играть

Двигайтесь клавишами **WASD** или **стрелками**. Удерживайте направление и нажмите **пробел**, чтобы перепрыгнуть центральный воздуховод. Между прыжками должно пройти три секунды. У обоих концов воздуховода есть обходы.

Подойдите к рыбке вплотную: она исчезнет у всех игроков, а на вашей панели появится «Рыбка в лапах». Кот переносит одну рыбку. Если двое коснутся одной рыбы, её получит игрок, чей допустимый контакт сервер обработал первым.

**Правила полного матча по плану команды.** Отнесите рыбку в коробку своего цвета, получите очко и отправляйтесь за следующей. Через пять секунд после сдачи рыбка возвращается на исходное место. Побеждает игрок с наибольшим счётом за 60 секунд; при равенстве максимальных результатов — ничья.

**Состояние прототипа.** Уже можно играть с отдельного клиента, бегать, прыгать и подбирать рыбок. Игрок пока отображается капсулой. Сдача и возрождение проверены программным вызовом. Для полноценного раунда осталось подключить коробки к сдаче, таймер, счёт и экран результата.

## Первый запуск

1. Клонируйте репозиторий. Версия Кати находится в ветке `feature/prediction`: до её слияния в `main` выполните в папке клона `git switch feature/prediction`. Установите Unity **6000.3.10f1** через Unity Hub.
2. В Unity Hub нажмите Add → Add project from disk и выберите папку с Assets, Packages и ProjectSettings. Откройте указанной версией редактора. При первом импорте нужен интернет для загрузки пакетов.
3. В Project откройте Assets/Rooftop/VentRoof.unity. Нажмите Play, затем «Создать игру». WASD или стрелки перемещают тестовую капсулу, пробел запускает прыжок. К рыбе нужно подойти вплотную. После подбора она исчезает у всех.
4. Для второго игрока откройте ту же сцену в сборке (File → Build Profiles → профиль своей ОС → Build And Run) или у коллеги в редакторе. Нажмите «Подключиться». На одном компьютере адрес 127.0.0.1, в общей локальной сети укажите локальный IPv4 хоста. Хост слушает UDP 7777. При запросе системы разрешите Unity входящие подключения.
5. У хоста должны отображаться два игрока. Проверьте движение обоих и одновременный подход к одной рыбе. Коробки пока служат ориентирами. Для игрового начисления очков нужен модуль матча.

## Как работать втроём

Передавайте через Git папки Assets вместе со всеми .meta, Packages, ProjectSettings и документы. Library и UserSettings создаются у каждого локально. Включены Visible Meta Files и Force Text. Все используют одну версию Unity. Карту редактирует Катя, кота — Арина, интерфейс и матч Ваня делает в собственных префабах. Интегрируйте их в карту по очереди.

Код и материалы передаются через GitHub. Основная ветка — `main`, работа Кати — `feature/prediction`. Для объединения изменений откройте Pull Request в `main`.

## Граница модулей

- PracticeCat поддерживает исходный серверный режим и режим предсказания. Клиент отправляет направление и запрос прыжка. Сервер ограничивает скорость, проверяет землю и трёхсекундный кулдаун, перемещает CharacterController. Катя реализовала локальное предсказание, сверку с сервером и повтор неподтверждённых команд. Арина подключает визуального кота.
- RoofFish принимает пересечение только на сервере. CatInventory допускает одну рыбку. Первый обработанный допустимый контакт получает её. При отключении владельца рыба возвращается на место.
- Ваня проверяет на сервере активность раунда и принадлежность коробки. Затем вызывает CatInventory.TryDeliver() и начисляет ровно одно очко при результате true. Через пять секунд после сдачи рыба снова доступна. Для боковой панели есть CatInventory.HasFish. При подключении матча добавьте проверку фазы раунда и при подборе.
- Порядок работ и критерии сдачи — в docs/TeamPlan.md.

## Проверить работу Кати

1. На хосте оставьте 12 рыбок для ПР‑4. На отдельном клиенте перед подключением выберите «Предсказание своего кота». Чтобы увидеть разницу, повторите прыжок с выключенной галочкой.
2. Для задержки на одном Mac запустите из корня проекта `python3 Tools/udp_lab.py --port 7778 --server 7777 --delay 100 --loss 0`. Хост работает на 7777, клиент подключается к 127.0.0.1 на **7778**. Для второго профиля перезапустите посредник с `--delay 175 --loss 4`. Закрыть его можно через Ctrl+C.
3. В режиме предсказания прыгните, дождитесь приземления и нажмите **F8** до истечения трёх секунд (на Mac при необходимости **Fn+F8**). Это учебная ошибка локального прогноза. Сервер отклонит ранний прыжок, клиент вернётся на крышу. В консоли хоста появится REJECT.
4. Для ПР‑5 включите на хосте «60 рыбок». Галочка «полная рассылка» включает учебный исходный режим. Без неё изменения состояния рассылаются через NetworkVariable. Выбирайте режим до запуска хоста.
5. Для автоматической проверки соберите **Development Build** для macOS. В корне репозитория выполните команды ниже, подставив путь к исполняемому файлу сборки. Тест сам запускает и останавливает свои процессы, использует только localhost и записывает результаты в указанную папку.

```sh
python3 Tools/check_practice.py prediction Builds/Rooftop.app/Contents/MacOS/game_cats Builds/check-prediction
python3 Tools/check_practice.py fish Builds/Rooftop.app/Contents/MacOS/game_cats Builds/check-fish
```
