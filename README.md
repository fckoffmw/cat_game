# Коты на крыше

Учебный 3D-прототип для ПР‑4 и ПР‑5. Редактор Unity **6000.3.10f1**, Netcode for GameObjects **2.7.0**, Unity Transport. Версии зависимостей закреплены в Packages/packages-lock.json.

## Первый запуск

1. В Unity Hub нажмите Add → Add project from disk и выберите папку с Assets, Packages и ProjectSettings. Откройте указанной версией редактора. При первом импорте нужен интернет для загрузки пакетов.
2. В Project откройте Assets/Rooftop/VentRoof.unity. Нажмите Play, затем «Создать игру». WASD или стрелки перемещают тестовую капсулу, пробел запускает прыжок. К рыбе нужно подойти вплотную. После подбора она исчезает у всех.
3. Для второго игрока откройте ту же сцену в сборке (File → Build Profiles → профиль своей ОС → Build And Run) или у коллеги в редакторе. Нажмите «Подключиться». На одном компьютере адрес 127.0.0.1, в общей локальной сети укажите локальный IPv4 хоста. Хост слушает UDP 7777. При запросе системы разрешите Unity входящие подключения.
4. У хоста должны отображаться два игрока. Проверьте движение обоих и одновременный подход к одной рыбе. Коробки пока служат ориентирами. Для игрового начисления очков нужен модуль матча.

## Как работать втроём

Передавайте через Git папки Assets вместе со всеми .meta, Packages, ProjectSettings и документы. Library и UserSettings создаются у каждого локально. Включены Visible Meta Files и Force Text. Все используют одну версию Unity. Карту редактирует Катя, кота — Арина, интерфейс и матч Ваня делает в собственных префабах. Интегрируйте их в карту по очереди.

В пустом репозитории GitVerse опубликуйте базу main. От неё создайте feature/prediction для сборки ПР‑4. Для параллельных модулей создайте отдельные ветки от общей базы, сливайте их через ревью в feature/prediction, затем оформите PR в main. Остальным достаточно клонировать репозиторий и добавить папку клона в Hub.

## Граница модулей

- PracticeCat — исходный серверный режим для сравнения. Клиент отправляет направление и запрос прыжка. Сервер ограничивает скорость, проверяет землю и трёхсекундный кулдаун, перемещает CharacterController. Арине принадлежит следующий этап — prediction и reconciliation.
- RoofFish принимает пересечение только на сервере. CatInventory допускает одну рыбку. Первый обработанный допустимый контакт получает её. При отключении владельца рыба возвращается на место.
- Ваня проверяет на сервере активность раунда и принадлежность коробки. Затем вызывает CatInventory.TryDeliver() и начисляет ровно одно очко при результате true. Через пять секунд после сдачи рыба снова доступна. Для боковой панели есть CatInventory.HasFish. При подключении матча добавьте проверку фазы раунда и при подборе.
- Порядок работ и критерии сдачи — в docs/TeamPlan.md.
