# Коты на крыше

Учебный 3D-прототип для ПР‑4 и ПР‑5. Редактор Unity **6000.3.10f1**, Netcode for GameObjects **2.7.0**, Unity Transport. Версии зависимостей закреплены в Packages/packages-lock.json.

## Как играть

Двигайтесь клавишами **WASD** или **стрелками**. Удерживайте направление и нажмите **пробел**, чтобы перепрыгнуть центральный воздуховод. Между прыжками должно пройти три секунды. У обоих концов воздуховода есть обходы.

Подойдите к рыбке вплотную: она исчезнет у всех игроков, а на вашей панели появится «Рыбка в лапах». Кот переносит одну рыбку. Если двое коснутся одной рыбы, её получит игрок, чей допустимый контакт сервер обработал первым.

**Правила полного матча по плану команды.** Отнесите рыбку в коробку своего цвета, получите очко и отправляйтесь за следующей. Через пять секунд после сдачи рыбка возвращается на исходное место. Побеждает игрок с наибольшим счётом за 60 секунд; при равенстве максимальных результатов — ничья.

**Состояние прототипа.** Уже можно играть с отдельного клиента, бегать, прыгать и подбирать рыбок. Игрок пока отображается капсулой. Сдача и возрождение проверены программным вызовом. Для полноценного раунда осталось подключить коробки к сдаче, таймер, счёт и экран результата.

## Первый запуск

1. Клонируйте репозиторий. Версия Кати находится в ветке `feature/prediction`: до её слияния в `main` выполните в папке клона `git switch feature/prediction`. Установите Unity **6000.3.10f1** через Unity Hub.
2. В Unity Hub нажмите Add → Add project from disk и выберите папку с Assets, Packages и ProjectSettings. Откройте указанной версией редактора. При первом импорте нужен интернет для загрузки пакетов.
3. В Project откройте Assets/Rooftop/VentRoof.unity. Нажмите Play, затем «Создать игру». WASD или стрелки перемещают тестовую капсулу, пробел запускает прыжок. К рыбе нужно подойти вплотную. После подбора она исчезает у всех.
4. Для второго игрока откройте ту же сцену в сборке (File → Build Profiles → профиль своей ОС → Build And Run) или у коллеги в редакторе. Нажмите «Подключиться». На одном компьютере адрес 127.0.0.1, в общей локальной сети укажите локальный IPv4 хоста. Хост слушает UDP 7777. При запросе системы разрешите Unity входящие подключения.
5. У хоста должны отображаться два игрока. Проверьте движение обоих и одновременный подход к одной рыбе. Коробки пока служат ориентирами. Для игрового начисления очков нужен модуль матча.

## Режимы хоста

Для обычной игры оставьте обе галочки выключенными. «60 рыбок» увеличивает количество предметов с 12 до 60. «Полная рассылка» включает периодическую отправку состояний рыбок примерно 10 раз в секунду для сравнения трафика в ПР‑5.
